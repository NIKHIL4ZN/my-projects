# Claims Management System

A full-stack enterprise web application that allows lecturers to submit claims and track approvals through a multi-level verification workflow.

## Features
- Lecturer claim submission with document uploads and notes  
- Multi-role system: Lecturer, Coordinator, Manager, HR  
- Real-time claim status tracking for all users  
- Encryption/decryption of sensitive data  
- CSV report generation for claims  
- Filters for claims by status, amount, date, and hourly rate  
- Admin functionality: user account management, hourly rate updates  
- Unit testing using xUnit  

## Tech Stack
- C# / ASP.NET MVC / .NET Core  
- Microsoft SQL Server (SSMS)  
- xUnit (Unit Testing)
