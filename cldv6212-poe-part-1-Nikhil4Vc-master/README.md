# Retail Store Web Application

A cloud-based e-commerce web application with separate admin and customer functionalities.

## Features
- Customer: view products, add to cart, checkout, track orders in real-time  
- Admin: manage users, add/edit/delete products, update order status  
- Secure contract document upload (encrypted/decrypted)  
- Real-time order tracking for customers  
- Unit testing implemented with xUnit  

## Tech Stack
- C# / ASP.NET MVC / .NET Core  
- Azure: App Service, Blob Storage, SQL Database, Queues  
- HTML / CSS  
- xUnit (Unit Testing)
