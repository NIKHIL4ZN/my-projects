### 💰 Budget Tracker (prog7313)

### 🤝 HustleHub+ (insy7314)

**Tech Stack** — JavaScript, React, Node.js, Express.js, MongoDB Atlas, Mongoose, Docker Compose, GitHub Actions

HustleHub+ connects clients looking for services with freelancers who publish gigs. I worked on the backend booking and income features. When a freelancer accepts a request, a MongoDB transaction keeps the booking update and its financial record together so the income dashboard reflects the accepted work.

**Key Features**

- Publish gigs and accept or decline booking requests
- Record accepted bookings as transactions and calculate income summaries
- Verify backend, frontend and browser workflows with 116 automated tests across the team’s test suites

### 📍 FamilyLink Live (prog7314)

**Tech Stack** — Kotlin, Android, Ktor, Retrofit, PostgreSQL, H2, Firebase, Azure Blob Storage

FamilyLink Live helps families and close friends coordinate everyday journeys. Members can share their location, get an alert when someone arrives at a saved place, or send an SOS when they need help. Our team paired a native Android client with a Kotlin REST API and Firebase push notifications.

- Share live locations and receive arrival or departure alerts

### 📡 Smart-X Engineering Console (prog7312)

**Tech Stack** — C#, ASP.NET Core Web API, Entity Framework Core, React, Vite, SQL Server, xUnit

Smart-X is an IoT prototype for investigating what happens across a sensor network. An operator can inspect timestamped readings, review queued commands and trace routes through a mesh. Simulating an offline node makes it possible to explore how a single failure changes connectivity.

**Key Features**

- Register sensors and inspect timestamped telemetry
- Process commands by priority and review command history
- Trace network routes and simulate offline nodes

I like taking a feature from its first database model through to an interface someone can use, then testing what happens when inputs are missing or an operation is repeated.
