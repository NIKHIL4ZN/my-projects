Overview
The cybersecurity awareness bot is designed to help users in understanding online security threats by providing clear definitions and tips on how to deal with these threats. The chatbot will help the users understand how cyber-attacks are carried out and ways of avoiding cyber-attacks. There are a variety of topics the Chabot covers such as the different types of cybersecurity threats and ways at dealing with the threats. The chatbot will also explain the definitions of different threat actors carrying out attacks as well as provide emotional support for the user.

Features  
•	Cybersecurity education: Provides definitions about threat actors carrying out cybersecurity threats and ways of avoiding them through phishing, password safety, safe browsing. 
•	Emotional support: Responds empathetically to users if they express concerns about cybersecurity threats.
•	Memory and recall: Remembers the users name and last accessed topic should the users want more information on the topic.
•	Interactive responses: Uses dynamic keyword matching for more accurate topic detection.
•	User friendly interface: Chatbots interface is basic and simple. Easy to use.
•	Mini-game quiz: Chatbot now has a quiz mini-game integrated in it to allow the user to answer cybersecurity related multiple choice and true/false questions to test the sharpness of the users.
•	Task manager: Chatbot has a reminder function that enables the user to add reminders.
•	Activity log: Chatbot has an activity log that saves the types of functionalities the user has requested from the chatbot and date/time at which the functionality was carried out.

How to use features:
•	Mini-game quiz: User should enter “start quiz” to start the quiz and “end quiz” to end the quiz function. Mini-game quiz scored may be found on the mini-game quiz screen.
•	Task manager: Users can add a reminder by stating “Remind me to [Task] in [Number] days. Tasks may be viewed on the task manager screen.
•	Activity log: Automatically adds requested activities to the activity log. Activity log may be viewed on the activity log screen.
Setup
•	Open the chatbot in an IDE like Visual studio or Visual studio code.
•	Ensure all dependencies needed for chatbot are installed.
•	Build and run the chatbot using C# runtime.
•	The chatbot will first need your name, there after you may interact with the chatbot by asking cybersecurity questions.

You may ask questions:
•	What is your purpose?
•	Dealing with cybersecurity threat actors.
•	How to avoid threats online?
•	What is phishing?
•	How to create a safe password?
•	Provide me with some safe browsing tips?
•	Give me more tips?
•	Explain more?
•	What are different types of threats online?

You may also greet the chatbot, ask its name and how it feels for exploration purposes.

Tech Stack
- C# / WPF / .NET  
- In-memory data storage (C# dictionaries)
